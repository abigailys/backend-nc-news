NC News API

An API for accessing and managing news articles, topics, and user comments. It allows developers to retrieve, post, and update data for a community-led news platform.

Available endpoints

  • GET /api/topics

    Retrieve a list of all topics.

    Example response:

      
{
  "topics": [
    {
      "slug": "coding",
      "description": "Code is love, code is life"
    },
    {
      "slug": "football",
      "description": "FOOTIE!"
    },
    {
      "slug": "cooking",
      "description": "Hey good looking, what you got cooking?"
    }
  ]
}

  • GET /api/articles

    Retrieve a list of all articles.

  • GET /api/users

    Retrieve a list of all users.

  • GET /api/articles/:article_id

    Retrieve article by article ID.

  • GET /api/articles/:article_id/comments

    Retrieve a list of comments for an article by article ID.

  • POST /api/articles/:article_id/comments

    Add a comment to an article.

  • PATCH /api/articles/:article_id

    Update an article by article ID.

  • CORE: DELETE /api/comments/:comment_id

    Delete a comment by comment ID.
