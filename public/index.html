NC News API

A RESTFUL API for accessing and managing news articles, topics, and user comments. It allows developers to retrieve, post, and update data for a community-led news platform.

Topics

  • GET /api/topics

    Retrieve a list of all available topics.

    Example response:

    {
  "topics": [
    {
      "slug": "coding",
      "description": "Code is love, code is life"
    },
    {
      "slug": "football",
      "description": "FOOTIE!"
    }
  ]
}

Articles

  • GET /api/articles

    Retrieve a list of all articles. Results are sorted by date (descending) by default.

    Acceptable Queries:

    Query Default Description
    sort_by created_at Any valid column (author, title, votes, etc.)
    order desc Sort order: asc or desc
    topic n/a Filter articles by a specific topic slug

    Example response:

    {
  "articles": [
    {
    author: "jessjelly",
    title: "Running a Node App",
    article_id: 1,
    topic: "coding",
    created_at: new Date(1604728980000),
    votes: 0,
    article_img_url:
      "https://images.pexels.com/photos/11035380/pexels-photo-11035380.jpeg?w=700&h=700",
    comment_count: 3
  },
  {
    author: "jessjelly",
    title: "The Rise Of Thinking Machines: How IBM's Watson Takes On The World",
    article_id: 2,
    topic: "coding",
    created_at: new Date(1589418120000),
    votes: 0,
    article_img_url:
      "https://images.pexels.com/photos/373543/pexels-photo-373543.jpeg?w=700&h=700",
    comment_count: 14
  },
  ]
}

  • GET /api/articles/:article_id

    Retrieve a single article object by its unique ID, including the comment count.

    Example response:

    {
  "article": {
    "author": "butter_bridge",
    "title": "Living in the shadow of a great man",
    "article_id": 1,
    "body": "I find this existence challenging",
    "topic": "mitch",
    "created_at": "2020-07-09T20:11:00.000Z",
    "votes": 100,
    "article_img_url": "https://images.pexels.com...",
    "comment_count": 11
  }
}

Comments

  • GET /api/articles/:article_id/comments

    Get all comments for a specific article, sorted by most recent first.

    Example response:

    {
  "comments": [
    {
      "comment_id": 5,
      "votes": 0,
      "created_at": "2020-11-03T21:00:00.000Z",
      "author": "icellusedkars",
      "body": "I replace the s with a z...",
      "article_id": 1
    },
    {
      "comment_id": 2,
      "votes": 14,
      "created_at": "2020-10-31T03:03:00.000Z",
      "author": "butter_bridge",
      "body": "The beautiful thing about treasure...",
      "article_id": 1
    }
  ]
}

  • POST /api/articles/:article_id/comments

    Post a new comment to an article.

    Required Request Body:

    {
  "username": "existing_user",
  "body": "Your comment text here"
}

    Example response:

    {
    username: existing_user, 
    body: Your comment text here
}

  • PATCH /api/articles/:article_id

    Update an article's vote count.

    Required Request Body:

    { "inc_votes": 1 } // or -100

    Example response:

    {
  "article": {
    "author": "butter_bridge",
    "title": "Living in the shadow of a great man",
    "article_id": 1,
    "body": "I find this existence challenging",
    "topic": "mitch",
    "created_at": "2020-07-09T20:11:00.000Z",
    "votes": 101,
    "article_img_url": "https://images.pexels.com...",
    "comment_count": 11
  }
}

  • DELETE /api/comments/:comment_id

    Remove a comment from the database. Responds with 204 No Content.

    Responds with status 204 and no content.
